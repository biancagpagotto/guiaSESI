<h1> — título

color — cor do texto

background — fundo

dir — lista arquivos e pastas

cd .. — volta uma pasta

cls — limpa a tela

mkdir — cria uma pasta

VS Code

Ctrl + S — salva o arquivo

Ctrl + Z — desfaz uma ação

Ctrl + F — procura um texto

Ctrl + / — comenta ou descomenta uma linha

Shift + Alt + F — formata o código

HTML no VS Code

Termos

Programação

HTML — estrutura da página

CSS — aparência da página

Tag — elemento do HTML

Seletor — indica o que será estilizado no CSS

Flexbox — organiza elementos em uma direção

Grid — organiza elementos em linhas e colunas

Link — leva a outra página ou recurso

Bug — erro em um código ou programa

Informática e redes

IP — endereço de um dispositivo na rede

Hub — conecta dispositivos em uma rede

Firewall — controla o tráfego de rede

Browser — programa para acessar sites

Download — recebe arquivos

Upload — envia arquivos
